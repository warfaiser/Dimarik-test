ПОЛОЖИ СВОИ ЗВУКИ В ЭТУ ПАПКУ
================================

Имена файлов (строго такие же, формат .mp3):

  wrong-1.mp3     — «звук 1» (неверный ответ)
  wrong-2.mp3     — «звук 2» (неверный ответ)
  wrong-3.mp3     — «звук 3» (неверный ответ)
  correct-1.mp3   — «звук 4» (верный ответ)
  correct-2.mp3   — «звук 5» (верный ответ)
  correct-3.mp3   — «звук 6» (верный ответ)

Неверные звуки (1–3) играют по очереди при ошибках,
верные (4–6) — по очереди при правильных ответах.

Если какого-то файла нет — вместо него автоматически
играет встроенный синтезированный звук, так что сайт
озвучен даже без файлов.

Проверить, какие файлы сайт «увидел», можно на стартовом
экране во вкладке «Звук».
