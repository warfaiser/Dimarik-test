ФОНОВАЯ МУЗЫКА
==============

Положи в эту папку mp3-файл с точным именем:

  portals.mp3     — «Portals» из фильма «Мстители: Финал» (Алан Сильвестри)

Что будет дальше:
  • трек заиграет автоматически после первого клика по сайту
    (требование браузеров — звук нельзя включать без жеста пользователя);
  • громкость плавно меняется по экранам:
      стартовый экран — тихо-атмосферно,
      квиз — совсем фоном, чтобы не мешать думать,
      результаты — торжественно громко;
  • в правом нижнем углу появится кнопка с эквалайзером —
    ей можно включать/выключать музыку;
  • во вкладке «Звук» на стартовом экране видно, нашёл ли сайт файл.

Обрати внимание: «Portals» — защищённая авторским правом композиция.
Используй легально приобретённый файл и не публикуй сайт с треком
в открытый доступ без прав на музыку.
